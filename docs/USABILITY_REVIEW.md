Status: **not yet performed.** Fill this in with real observations only.

## How to run it (about 15 minutes per person)

1. Ask 3–5 classmates who have not seen the project.
2. Start the app with AUTO left off, and run the flood demo once.
3. Give only the tasks below. Do not help unless they are stuck; note when they are.

| # | Task |
|---|---|
| 1 | Register a resource |
| 2 | Report a new incident with coordinates |
| 3 | Find its priority rank and say why it has that rank |
| 4 | Find the recommendation and say why that resource was chosen |
| 5 | Approve it, create a response plan and approve the plan |
| 6 | Resolve the incident and find the change in Activity History |
